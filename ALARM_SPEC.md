## 1. Продукт

Настольный будильник для одного пользователя в стиле приложения «Часы» от Apple. Тёмная тема по умолчанию, светлая — по выбору.

| Принцип | Требование |
|---|---|
| Платформа | Только десктоп: Windows, macOS, Linux. Мобильной версии нет. |
| Без сети | Работает полностью без интернета. Внешних API и облака нет. |
| Без аккаунтов | Регистрации и входа нет, один локальный пользователь. |
| Изоляция | Каждый пользователь ОС видит только свои данные. |
| Хранение | Всё хранится локально на компьютере. Синхронизации нет. |
| Звонок в фоне | Будильник **должен** звонить, когда окно свёрнуто, скрыто или экран заблокирован. Нативные реализации **должны** звонить и при закрытом окне (см. [7](#7-платформенно-зависимое-не-переносить-1-в-1)). |

**Разделы приложения:** Alarms (будильники), Stopwatch (секундомер), Timer (таймер), Settings (настройки).

### 2.4 Таймер (одно состояние на приложение)

`status` (`idle` · `running` · `paused` · `ringing`), `durationMs` (по умолчанию 5 мин, минимум 1 с), `endsAt`, `remainingMs`, `label` (≤ 60), `sound` (по умолчанию `Chimes`), `recents` (до 6 записей `{durationMs, label}`, новые сверху, без повторов по длительности).

`id`, `name` (имя файла без расширения), `size`, `addedAt` и **сам файл**: он копируется в хранилище приложения, ссылки на исходный путь нет.

### 2.7 Требования к хранению

- Всё из раздела 2 сохраняется локально и переживает перезапуск приложения и компьютера.
- Повреждённая запись **пропускается** (будильник) или заменяется значением по умолчанию (настройка), но не роняет приложение.
- Состояния таймера и секундомера сохраняются: запущенный таймер или секундомер продолжает идти после перезапуска.

## 3. Функциональность

### 3.1 Навигация

- Верхняя панель с сегментным переключателем из четырёх разделов: `Alarms`, `Stopwatch`, `Timer`, `Settings`. При запуске открываются Alarms.
- Горячие клавиши: **⌘/Ctrl + 1…4** переключают разделы.
- Справа на панели — текущее время в выбранном формате, обновляется раз в секунду.

### 3.2 Список будильников

- **Сортировка:** по времени суток (час, минута), при равенстве — по дате создания.
- **Строка будильника:**
  - время крупно; в формате 12h добавляется `AM`/`PM` меньшим кеглем;
  - под временем подзаголовок: `<label>`, а если есть повтор — `<label>, <сводка повтора строчными>`. Примеры: `Work, weekdays`, `Gym`, `Take vitamins, every day`;
  - переключатель вкл/выкл справа.
- **Активность:** будильник активен, если он включён или отложен. Неактивный показывается вторичным цветом (`label-2`).
- **Отложенный будильник:** под подзаголовком оранжевая строка `Snoozed until HH:MM` и маленькая кнопка-пилюля `Stop`, которая отменяет отсрочку.
- **Открытие редактора:** клик по строке в любом месте, кроме переключателя.
- **Подзаголовок страницы** обновляется не реже раза в 15 секунд:
  - `Next alarm in <относительное время>` — ближайший звонок среди включённых и отложенных будильников;
  - `No alarms on` — если таких нет.
- **Кнопки в шапке:**
  - `Edit`/`Done` слева — только если есть хотя бы один будильник;
  - `+` справа — только если есть хотя бы один будильник. В пустом состоянии добавление идёт через большую кнопку `Add Alarm`.
- **Пустое состояние:** иконка будильника, `No Alarms`, `Add an alarm to wake up on time.`, кнопка `Add Alarm`.
- **Режим Edit:**
  - слева от каждой строки красный круг «−», вместо переключателя — шеврон;
  - клик по «−» поворачивает его на −90° и показывает справа красную кнопку `Delete` на всю высоту строки;
  - повторный клик по «−» прячет `Delete`;
  - `Delete` удаляет будильник сразу, без подтверждения.
- **Переключатель:**
  - включение пересчитывает `nextTriggerAt` от текущего момента и снимает отсрочку;
  - выключение обнуляет `nextTriggerAt` и снимает отсрочку.

### 3.3 Редактор будильника

Модальное окно (sheet). Заголовок: `Add Alarm` для нового будильника, `Edit Alarm` для существующего. Слева `Cancel`, справа жирная `Save`.

- **Cancel**, **Esc** или клик по затемнённому фону закрывают окно без сохранения.
- **Save:**
  - сохраняет будильник со значением `enabled = true` — сохранение всегда включает будильник;
  - пересчитывает `nextTriggerAt` от текущего момента;
  - сбрасывает отсрочку и признак звонка;
  - закрывает окно сразу, не дожидаясь записи на диск.

**Главная страница редактора (сверху вниз):**

1. **Барабан времени** (см. 4.4.6): часы `00…23` и минуты `00…59` через двоеточие. В формате 12h — часы `1…12`, минуты и третий барабан `AM`/`PM`.
2. **Секция без заголовка:**
   - `Repeat` — справа сводка повтора и шеврон, ведёт на подстраницу;
   - `Label` — поле ввода прямо в строке, выравнивание вправо, плейсхолдер `Alarm`, максимум 60 символов;
   - `Sound` — справа имя звука и шеврон, ведёт на подстраницу;
   - `Snooze` — переключатель.
3. **Секция `VOLUME`:**
   - ползунок громкости между иконками тихого и громкого динамика;
   - `Gradual Volume` — справа значение (`Off`, `15 sec`, `1 min` …) и шеврон, ведёт на подстраницу;
   - `Preview Wake-up` (оранжевый текст) проигрывает звук будильника с текущими громкостью и нарастанием, по кругу. Во время проигрывания строка меняется на `Stop Preview`, повторный клик останавливает. Уход со страницы или закрытие окна тоже останавливают звук.
   - Футер: `Starts almost silent and rises smoothly to the set volume.`
4. **Секция `TURN OFF`:**
   - `Turn Off With` — справа сводка задания и шеврон, ведёт на подстраницу;
   - Футер: `The alarm keeps ringing until the task is solved. Snooze never needs a task.`
5. **Только для существующего будильника:** отдельная секция с красной строкой `Delete Alarm`. Удаляет будильник и закрывает окно.

**Подстраницы.** Въезжают справа с анимацией push-in, в шапке `‹ Back` и заголовок подстраницы, без кнопки Save. Изменения на подстраницах применяются к черновику, а сохраняются только по `Save` на главной.

| Подстраница | Заголовок | Содержимое |
|---|---|---|
| Repeat | `Repeat` | 7 строк в порядке с понедельника: `Every Monday` … `Every Sunday`. Множественный выбор, выбранные отмечены оранжевой галочкой. |
| Sound | `Sound` | Выбор звука (см. 3.8). |
| Gradual Volume | `Gradual Volume` | 7 строк: `Off`, `15 sec`, `30 sec`, `1 min`, `2 min`, `5 min`, `10 min`, выбор галочкой. Футер: `How long it takes to reach full volume.` |
| Turn Off With | `Turn Off With` | Сегменты `None` · `Math` · `Retype Code`. Если не `None`: секция `DIFFICULTY` с сегментами `Easy` · `Medium` · `Hard`; строка `N task(s) in a row` со степпером 1–5 (`1 task in a row`, `2 tasks in a row`); секция `EXAMPLE` с примером задания крупным шрифтом (у математики в конце ` = ?`). Пример пересоздаётся при каждом изменении настроек задания. |

**Сводки:**

- **Повтор:**

  | Выбранные дни | Сводка |
  |---|---|
  | нет | `Never` |
  | все 7 | `Every day` |
  | Пн–Пт | `Weekdays` |
  | Сб + Вс | `Weekends` |
  | один день | `Every <полное имя дня>`, например `Every Wednesday` |
  | другое | короткие имена через пробел в порядке с понедельника: `Mon Fri Sun` |

- **Задание:** `None`, либо `Math · Medium · 2×` / `Retype Code · Hard · 1×`.
- **Длительность нарастания:** `Off`, `N sec`, `N min`, `N min N sec`.

### 3.4 Расписание и срабатывание

**Следующий звонок `nextOccurrence(after)`** — первый момент **строго позже** `after` в локальном времени, когда:

- `hour:minute`, если `days` пуст;
- иначе — `hour:minute` в ближайший день из `days`. Поиск идёт до 8 дней вперёд.

Переходы на летнее и зимнее время обрабатываются средствами локального календаря.

**Цикл проверки:**

- Проверка идёт **не реже раза в 0,5 с** и сразу при возврате окна в фокус.
- На каждой проверке для каждого будильника принимается одно решение:

| Условие | Решение |
|---|---|
| будильник уже звонит (`ringingSince` задан) | ждать |
| `snoozeUntil` задан и наступил | звонить, если опоздание ≤ grace; иначе — пропущен |
| будильник выключен или нет `nextTriggerAt` | ждать |
| `now ≥ nextTriggerAt` | звонить, если опоздание ≤ grace; иначе — пропущен |
| иначе | ждать |

`grace` — это настройка `missedGraceMinutes`, по умолчанию 60 минут.

**Звонок:**

1. Записать `ringingSince = now`.
2. Обновить расписание:
   - звонок после отсрочки: только сбросить `snoozeUntil`;
   - плановый звонок одноразового будильника: `enabled = false`, `nextTriggerAt = пусто`;
   - плановый звонок повторяющегося будильника: `nextTriggerAt = nextOccurrence(max(now, trigger))`, то есть следующий день из расписания.
3. Начать звук будильника (см. 3.9) и показать экран звонка (3.5).
4. Отправить системное уведомление: заголовок `⏰ <label>`, текст `<время>\nOpen the app to turn it off.`.
   - уведомление не исчезает само;
   - если у будильника включён snooze, в уведомлении есть кнопка `Snooze N min`.

**Пропущенный будильник:**

- расписание обновляется так же, как при звонке, но без звука;
- если опоздание меньше 12 часов, приходит уведомление `Missed alarm: <label>` с текстом `It was set for <время>, while the computer was asleep or the app was closed.`.

**Надёжность:**

- Состояние «звонит» сохраняется: после перезапуска приложения звонок продолжается.
- Если одновременно звонят несколько будильников, играют звуки всех, а экран звонка показывает первый по сортировке. После его выключения показывается следующий.
- Будильник звонит **ровно один раз**, даже если открыто несколько окон или экземпляров приложения.
- Изменения из одного окна сразу видны в остальных.

### 3.5 Экран звонка

Полноэкранный слой поверх всего приложения, **всегда тёмный** независимо от темы. Заголовок окна или вкладки меняется на `⏰ <label>`, после выключения возвращается прежний.

**Состав:**

- строка с иконкой будильника (оранжевой) и названием будильника;
- текущее время очень крупно и тонко; в формате 12h с `AM`/`PM`;
- дата: `<день недели>, <месяц> <число>`, например `Tuesday, November 10`;
- за временем — пульсирующее оранжевое радиальное свечение (анимация breathe).

**Кнопки:**

- `Snooze · N min` — оранжевая заливка, высота 60, на всю ширину колонки. Есть, только если у будильника включён snooze. Фокус при открытии по умолчанию на ней.
- `Stop` — полупрозрачная серая, высота 60. Если snooze выключен, фокус по умолчанию на ней.

**Поведение:**

- `Snooze`:
  - звук останавливается с затуханием;
  - `snoozeUntil = now + snoozeMinutes`, `ringingSince` сбрасывается;
  - уведомление закрывается.
- `Stop` при задании `None`: будильник сразу выключается.
- `Stop` при задании: показывается **карточка задания**, звук продолжает играть.
  - Слева заголовок: `Solve to turn off` для математики, `Type the code to turn off` для кода. Справа — индикатор прогресса из N точек, решённые становятся зелёными.
  - Задание крупным шрифтом. У математики в конце ` =`. Код показан группами по 4 символа.
  - Поле ввода: фокус ставится автоматически, плейсхолдер `Answer` (математика, цифровая клавиатура) или `Code`, текст по центру, крупный, отображается заглавными. Рамка фокуса — 2 px оранжевая.
  - `Done` — оранжевая кнопка, неактивна при пустом поле. **Enter** тоже отправляет ответ.
  - **Верный ответ:** точка прогресса становится зелёной и показывается следующее задание. После последнего будильник выключается.
  - **Неверный ответ:** задание трясётся (анимация shake) и заменяется **новым**, поле очищается, прогресс не сбрасывается.
  - `Back` (вторичный текст) возвращает к кнопкам Snooze/Stop.
- **Выключение будильника:** `ringingSince` и `snoozeUntil` сбрасываются, звук останавливается, уведомление закрывается.

### 3.6 Генерация заданий

`rand(a, b)` — равномерное целое из диапазона, включая концы.

| Сложность | Математика | Код (retype) |
|---|---|---|
| Easy | 50/50: `a + b` (a ∈ 12–59, b ∈ 11–39) или `(a+b) − b` с ответом `a` | 6 символов |
| Medium | `a × b + c` (a ∈ 3–9, b ∈ 12–29, c ∈ 11–89) | 10 символов |
| Hard | `a × b − c × d` (a ∈ 6–19, b ∈ 13–49, c ∈ 3–9, d ∈ 11–29); ответ может быть отрицательным | 14 символов |

- **Знаки в задании:** `×` для умножения и `−` (U+2212) для вычитания, по пробелу с каждой стороны.
- **Алфавит кода:** `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`. Нет похожих символов `I`, `O`, `0`, `1`.
- **Проверка математики:** пробелы игнорируются; `−` и `–` считаются обычным минусом.
- **Проверка кода:** регистр и пробелы игнорируются.

### 3.7 Отсрочка (Snooze)

- Длительность — настройка `snoozeMinutes`, по умолчанию 9 минут.
- Откладывать можно сколько угодно раз подряд.
- Задание для отсрочки не требуется.
- Отложенный будильник прозвенит, даже если он одноразовый и уже выключился.
- Отменить отсрочку можно кнопкой `Stop` в строке списка.
- Отложить можно и кнопкой в системном уведомлении.

### 3.8 Звуки

**Встроенные звуки.** Генерируются программно или поставляются файлами; звучание должно совпадать с описанием. Все зациклены. Колокол — сумма гармоник ×1, ×2, ×2.76, ×5.4 с амплитудами 1, 0.5, 0.35, 0.15 и затуханием 100 %, 70 %, 50 %, 30 % длительности.

| Название (UI) | Длина цикла | Рисунок |
|---|---|---|
| `Sunrise` (по умолчанию для будильника) | 4.8 с | Колокола-арпеджио C5 E5 G5 C6 G5 E5 с шагом 0.4 с (затухание 2.2 с), затем тише G5 B5 D6 с 2.6 с с шагом 0.35 с |
| `Harp` | 3.2 с | Треугольная волна, восходящее арпеджио C4 E4 G4 B4 C5 E5 G5 B5 с шагом 0.11 с (затухание 1.9 с), затем C6 G5 E5 с 1.5 с с шагом 0.18 с |
| `Chimes` (по умолчанию для таймера) | 3.6 с | Колокола G5 E5 C5 D5 A5 G5 на 0, 0.45, 0.9, 1.35, 1.95, 2.4 с |
| `Beacon` | 2.0 с | 4 коротких сигнала по 0.12 с, 1046.5 Гц (C6) с тихим обертоном 1568 Гц, шаг 0.16 с, затем тишина |
| `Pulse` | 1.6 с | 3 «пика» прямоугольной волны 1000 Гц по 0.12 с с шагом 0.2 с (классический электронный будильник) |
| `Classic Bell` | 2.0 с | 24 быстрых чередующихся удара колокола 1760 / 1975.5 Гц с шагом 0.05 с (механический звонок) |

**Свои мелодии:**

- Принимаются аудиофайлы MP3, M4A, AAC, WAV, OGG/OGA, OPUS, FLAC, WEBM размером до **80 МБ**.
- Перед сохранением файл проверяется пробным декодированием.
- Ошибки показываются в футере секции вместо обычного текста:
  - `That file is not an audio file.`
  - `That file is larger than 80 MB.`
  - `This audio format cannot be played by your browser.` *(платформа: слово «browser» заменить)*
- Имя в списке — имя файла без расширения. Список отсортирован по имени.
- Если файл выбранного звука удалён, вместо его имени показывается `Missing file`, а звонит `Sunrise`.

**Выбор звука (sheet или подстраница):**

- **Секция `YOUR MUSIC`:**
  - свои файлы — строки с фиолетовой (indigo) иконкой ноты;
  - строка `Choose a File…` (оранжевая, с `+`) открывает системный диалог выбора файла; во время загрузки — `Adding…`. Добавленный файл сразу выбирается.
  - Футер: `Music files stay on this computer. MP3, M4A, WAV, OGG and FLAC are supported.`
- **Секция `BUILT-IN SOUNDS`:** 6 встроенных звуков.
- Выбранный звук отмечен оранжевой галочкой.
- Клик по звуку выбирает его и **один раз проигрывает** без нарастания на громкости будильника (в таймере — 0.9). Звук прерывается при следующем выборе и при уходе со страницы.

### 3.9 Громкость и нарастание

- **Кривая нарастания:** `gain(t) = volume × (0.015 + 0.985 × x²)`, где `x = t / rampSeconds` от 0 до 1. Звук начинается почти беззвучно (1.5 %) и растёт квадратично. После окончания нарастания громкость остаётся на уровне `volume`.
- `rampSeconds = 0`: звук сразу на полной громкости.
- **Остановка звука** — всегда с коротким затуханием: 120 мс в общем случае, 250 мс при выключении будильника.
- Звук будильника зациклен до выключения или отсрочки.

### 3.10 Таймер

**Неактивное состояние (idle):**

- Три барабана: часы `0…23` с подписью `hours`, минуты `0…59` с подписью `min`, секунды `0…59` с подписью `sec`. Подписи жирные и неподвижные, стоят справа от барабанов.
- Длительность не может быть меньше 1 секунды. Выбранная длительность сохраняется сразу.
- Кнопки:
  - `Cancel` — серая, неактивна;
  - `Start` — зелёная, запускает таймер на выбранную длительность.

**Работа (running или paused):**

- Вместо барабанов — кольцо прогресса диаметром 280, толщиной 8: оранжевая дуга на сером фоне, убывает по часовой стрелке.
- Внутри кольца:
  - название таймера (`Timer`, если пусто);
  - обратный отсчёт крупно: `MM:SS` или `H:MM:SS`, с округлением вверх до секунды;
  - иконка колокольчика и время окончания (на паузе — время, когда таймер закончился бы при продолжении сейчас, более бледным цветом).
- Кнопки:
  - `Cancel` — серая, активна: сбрасывает таймер в idle;
  - `Pause` (оранжевая) или `Resume` (зелёная).

**Под кнопками (всегда):**

- Секция со строками:
  - `Label` — поле ввода прямо в строке, плейсхолдер `Timer`;
  - `When Timer Ends` — справа имя звука, открывает sheet `When Timer Ends` со своей кнопкой `Done` и выбором звука из 3.8.
- Секция `RECENTS` (только если не пуста), строки:
  - длительность крупно;
  - под ней название таймера или словесная длительность (`5 min`, `10 min 30 sec`, `1 hr 2 min`);
  - справа круглая зелёная кнопка ▶ — запускает этот таймер с его названием;
  - при наведении на строку появляется текстовая кнопка `Remove`.

**Окончание:**

- Таймер переходит в состояние `ringing`. Звук выбранного звука на громкости 0.9 с нарастанием 3 с, зациклен.
- Системное уведомление `⏱ <label>` с текстом `<MM:SS> timer is done.`, не исчезает само.
- Поверх всего — **окно-алерт**: иконка таймера (оранжевая), название, `<MM:SS> is up`, кнопки `Stop` (оранжевая, фокус) и `Repeat` (серая).
  - `Stop` возвращает таймер в idle;
  - `Repeat` перезапускает таймер на ту же длительность.
- Если таймер должен был закончиться **больше 10 минут назад** (компьютер спал): не звонить, перейти в idle и отправить уведомление `<label> ended` с текстом `Your <MM:SS> timer finished while the computer was asleep.`.

**Recents:**

- При каждом старте длительность добавляется в начало списка.
- Запись с той же длительностью заменяется.
- В списке максимум 6 записей.

**Где работает:** таймер идёт и звонит на любой вкладке приложения, не только на Timer.

### 3.11 Секундомер

- **Формат:** `MM:SS.cc` (сотые доли); если прошло больше часа — `H:MM:SS.cc`. Обновляется каждый кадр.
- **Кнопки:**

  | Состояние | Левая кнопка (серая) | Правая кнопка |
  |---|---|---|
  | Идёт | `Lap` | `Stop` (красная) |
  | Стоит | `Reset` (неактивна при 0) | `Start` (зелёная) |

- **Горячие клавиши** (не срабатывают при фокусе в поле ввода):
  - **Пробел** — Start/Stop;
  - **L** — Lap, когда секундомер идёт; Reset, когда стоит и время больше 0.
- **Список кругов:** под кнопками, разделён линиями. Сверху текущий круг (`Lap N`, время идёт), ниже завершённые круги от новых к старым.
- **Подсветка:** при 2 и более завершённых кругах самый быстрый — зелёный, самый медленный — красный. Текущий круг не подсвечивается.
- **Сохранение:** состояние и круги переживают перезапуск. Если секундомер шёл, после перезапуска он продолжает идти.

### 3.12 Настройки

Секции сверху вниз:

1. **`APPEARANCE`**
   - `Theme`: сегменты `Auto` · `Light` · `Dark`, ширина 220. Применяется мгновенно, `Auto` следует системной теме в реальном времени.
   - `Time Format`: сегменты `Auto` · `12-hour` · `24-hour`. Влияет на все отображения времени.
2. **`NEW ALARM DEFAULTS`**
   - `Sound` — sheet `Default Sound` с выбором звука;
   - ползунок громкости;
   - `Gradual Volume` — выпадающий список вариантов;
   - `Turn Off With`: сегменты `None` · `Math` · `Code`;
   - если не `None`: `Difficulty` (сегменты) и `N tasks in a row` (степпер 1–5).
   - Футер: `Applied to alarms you create from now on. Each alarm can still be changed individually.`
3. **`SNOOZE`**
   - `Snooze Length · N min` со степпером 1–30.
4. **`RELIABILITY`**
   - `Notifications`: статус `On` (зелёный), `Blocked …` (оранжевый) или кнопка `Turn On`, которая запрашивает разрешение;
   - `Alarm Sound`: статус готовности звука *(платформа)*;
   - `Keep Computer Awake`: переключатель. Пока включён и есть включённый, отложенный или звонящий будильник, компьютер не должен засыпать по бездействию;
   - `Ring Late Alarms For`: выпадающий список `5 min`, `15 min`, `30 min`, `1 hr`, `2 hr`, `4 hr`;
   - футер с объяснением ограничений платформы *(платформа)*.
5. **`YOUR MUSIC`**
   - свои файлы: иконка ноты, имя, размер `X.X MB`, иконка корзины (серая, красная при наведении) — удаляет файл сразу;
   - строка `Add Music File…`;
   - футер: `Imported files are copied into the app’s local storage, so alarms keep working if the original is moved.`
6. **`ABOUT`**
   - `Version` — номер версии;
   - `Storage` — `This computer only`.

Все изменения настроек применяются и сохраняются сразу, кнопки «Сохранить» нет.

### 3.13 Форматы времени

| Где | Правило |
|---|---|
| Время будильника, 24h | `HH:MM` с ведущим нулём: `06:30` |
| Время будильника, 12h | `H:MM` + `AM`/`PM`; 0 ч → `12 AM`, 12 ч → `12 PM` |
| Относительное время | меньше минуты → `less than a minute`; иначе округление до минут: `45 min`, `7 hr 12 min`, `1 day 3 hr`, `2 days` (при наличии дней минуты не показываются) |
| Обратный отсчёт таймера | `MM:SS` или `H:MM:SS`, секунды округляются вверх |
| Секундомер | `MM:SS.cc` или `H:MM:SS.cc` |
| Дата на экране звонка | `Weekday, Month D` (англ.) |

### 3.14 Уведомления

- Разрешение запрашивается **только** по действию пользователя: кнопкой `Turn On` в баннере на Alarms или в Settings.
- Клик по уведомлению выводит окно приложения на передний план; если окна нет, приложение открывается.
- Кнопка `Snooze` в уведомлении откладывает будильник, не открывая окно.
- Баннеры на странице Alarms:
  - **разрешение ещё не запрошено:** `Allow Notifications` / `So alarms reach you even when the app is minimised or behind other windows.` / кнопка `Turn On`;
  - **запрещено:** `Notifications are blocked` / `Alarms still ring while the app is open, but you will not see them when the window is hidden. …` *(платформа: вторая фраза зависит от ОС)*.

| Иконка `+` | Оранжевая, 24, зона нажатия 36 × 36 с круглой подсветкой `fill-2` при наведении. |

**4.4.6 Барабан (wheel picker)**

- Строка высотой 36, видно 5 строк (высота 180). Полоса выбора `fill-2` со скруглением 8 проходит под всеми барабанами группы по центру.
- Верх и низ плавно исчезают: маска-градиент, прозрачность у краёв, полная видимость от 32 % до 68 % высоты.
- Цифры 23, моноширинные. Строка под полосой — цвет `label`, остальные — `label-2`. Подсветка меняется **сразу во время прокрутки**, с переходом 150 мс.
- Ввод:
  - перетаскивание мышью, движение 1 : 1 с указателем; захват сохраняется, даже если указатель ушёл за барабан или за окно;
  - колесо мыши и трекпад;
  - клик по строке;
  - клавиши ↑/↓, PageUp/PageDown (±5), Home/End.
- **Доводка:** после отпускания, окончания прокрутки (90 мс без событий) или нажатия клавиши барабан **плавно** доезжает до ближайшей строки за 160–520 мс (растёт с расстоянием) по кривой ease-out-cubic. Значение фиксируется по окончании доводки. **Рывков и перескоков быть не должно.**
- **Инерция (бросок):** учитывается скорость за последние 80 мс перед отпусканием. Если она больше 0.3 px/мс, барабан прокатывается дальше в **ту же сторону** на `скорость × 110 px`, но не больше 6 строк. Если перед отпусканием была пауза или смена направления, броска нет.
- Новое вращение колеса прерывает идущую доводку. Повторные клавиши во время доводки отсчитываются от строки, к которой барабан едет.
- Курсор: «рука» (grab), при перетаскивании — «схваченная рука» (grabbing).
- Неподвижные подписи единиц (`hours`, `min`, `sec`) — 17 Semibold справа от своего барабана.

**4.4.7 Строка списка (Row)**

- Варианты: текст с шевроном; со значением справа; с переключателем, степпером или кнопкой справа; с галочкой (выбор); с полем ввода в строке (подпись слева, ввод справа, без рамки и кольца фокуса); с иконкой слева; цветной текст (`accent` или `red`).
- Кликабельная строка подсвечивается `cell-hover` при наведении и нажатии.

**4.4.8 Баннер** — карточка: цветная иконка слева, жирный заголовок 15, пояснение 13 `label-2`, справа необязательная кнопка-пилюля.

**4.4.9 Иконки** — линейные, толщина 1.8, скруглённые концы, в стиле SF Symbols: будильник, секундомер, таймер, шестерёнка, плюс, шевроны ‹ ›, галочка, минус в круге (заливка), колокольчик (заливка), динамик, нота, play (заливка), корзина.

## 7. Платформенно-зависимое (не переносить 1 в 1)

Эталон — веб-приложение (PWA). Перечисленные ниже элементы существуют **только из-за ограничений браузера**. В нативной реализации их нужно заменить эквивалентом или убрать.

| Элемент эталона | Почему есть | Что делать в другой реализации |
|---|---|---|
| Полоса под панелью: «Click anywhere to enable alarm sound. Browsers need one click after opening…» | браузер не играет звук до первого клика | Убрать, если платформа играет звук без жеста. |
| Строка `Alarm Sound` (`Ready` / `Click anywhere to enable` / `Unsupported`) в Reliability | то же | Убрать или показывать реальный статус аудиоустройства. |
| Футер Reliability «This is a web app: it rings while its window or tab is open … It cannot ring while the browser is fully quit…» | веб не может звонить при закрытом браузере | Заменить честным текстом про свою платформу, например: «Alarm keeps running in the menu bar / tray and rings even when its window is closed.» |
| Звонок только при открытом окне | ограничение веба | **Нативные реализации обязаны звонить при закрытом окне:** фоновый процесс или агент, иконка в трее или строке меню, звонок при заблокированном экране. Это исходное критическое требование продукта. Желателен автозапуск при входе в систему (настройка `Open at Login`, если добавляется — секция Reliability). |
| `Keep Computer Awake` через блокировку сна экрана | у веба доступен только запрет гашения экрана при видимой вкладке | В нативной версии — системный запрет **сна системы** (экран может гаснуть) на время, пока есть активные будильники. Если ОС поддерживает пробуждение по расписанию, использовать его. |
| Статус `Blocked in browser` и текст баннера про «site settings» | разрешения браузера | Формулировка для своей ОС: «Allow notifications in System Settings → Notifications». |
| Текст ошибки «…cannot be played by your browser.» | | «…cannot be played on this computer.» |
| Синхронизация вкладок и «звонит только одна вкладка» | можно открыть несколько вкладок | Обеспечить единственный экземпляр приложения или единый фоновый процесс. |
| Установка как приложение, service worker, кэш для офлайна | особенности PWA | Не нужно: нативное приложение офлайн изначально. |
| `Version` показывает версию пакета | | Версия приложения. |

**Должно остаться 1 в 1 на любой платформе:** раздел 3 целиком (кроме пометок *(платформа)*), раздел 4, тексты раздела 6.

## 8. Чек-лист приёмки

**Будильники:**
- [ ] Создание, редактирование и удаление (из редактора и в режиме Edit); переключатель вкл/выкл.
- [ ] Повтор по дням; сводки повтора в точности как в 3.3.
- [ ] Одноразовый будильник после звонка выключается; повторяющийся переносится на следующий день из расписания.
- [ ] Звонит с точностью ≤ 1 с при свёрнутом или скрытом окне и заблокированном экране; нативная версия — и при закрытом окне.
- [ ] После сна компьютера: опоздание ≤ grace — звонит; больше — уведомление `Missed alarm`.
- [ ] Звонок переживает перезапуск приложения.
- [ ] Будильник звонит ровно один раз при нескольких окнах или экземплярах.

**Звук:**
- [ ] Нарастание громкости по кривой из 3.9; `Off` — сразу полная громкость.
- [ ] Шесть встроенных звуков звучат по описанию.
- [ ] Свой файл: проверка формата и размера (80 МБ), копия хранится локально, удаление; при отсутствии файла звучит `Sunrise`, в UI — `Missing file`.

**Отсрочка и выключение:**
- [ ] Snooze на N минут, повторяемый, из экрана звонка и из уведомления; отмена из списка.
- [ ] Задания: генерация по таблице 3.6; неверный ответ — тряска и новое задание; 1–5 заданий подряд с индикатором; Snooze не требует задания.
